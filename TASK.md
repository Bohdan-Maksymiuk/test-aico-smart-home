# Smart Home Device Manager

## Overview

Build a small full-stack application for managing IoT devices in a smart home environment.

The application should allow users to view and manage connected devices, such as smart lights or thermostats, through a simple interface.

We're interested in seeing how you approach a relatively straightforward problem, the technical decisions you make, and the overall quality of your implementation.

## Objectives

Your application should include:

- **API:** A RESTful API supporting operations like device creation, retrieval, updates, and deletion.
- **Front end:** A simple interface that displays devices and allows users to interact with them.
- **Data layer:** A way to store and manage device information and state.

## Expectations

You are free to use any technologies, frameworks, and storage solutions you feel are appropriate.

We're not looking for a large or feature-rich application. We'd much rather see a smaller, well-implemented solution that demonstrates good engineering practices and thoughtful decision-making.

Make reasonable assumptions where needed. Consider how your application should behave in normal use, as well as when things don't go as expected. Think about what makes a good API, a good front end, and a solid DB solution, and nail that.

## Deliverables

Please provide a link to a public GitHub repository containing your solution.

Include a README covering:

- Instructions for running the application.
- A brief explanation of your technology choices and any key decisions or assumptions.
- Anything you'd improve or approach differently given more time.
- A nod to how you would deploy this to a cloud platform.

We value the quality of your approach. We do not necessarily discourage the usage of AI, but you must be able to talk about your code and decision-making in depth in person.
